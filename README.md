## How to Access the App

This is a Next.js web application. To work with it:

1.  **Open a Terminal** in this folder.
2.  **Run the command:**
    ```bash
    npm run dev
    ```
    > **Note for Windows Users:** If you see an error like `running scripts is disabled on this system`, try using **Command Prompt (cmd)** instead of PowerShell, or run this command instead:
    > ```bash
    > npx next dev
    > ```
3.  **Open your browser** and go to:
    [http://localhost:3000](http://localhost:3000)

The app will start, and you will be redirected to the Login page. Create an account to get started.


You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
